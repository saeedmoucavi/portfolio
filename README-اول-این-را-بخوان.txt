این ۶ فایل باید روی گیت‌هاب جایگزین شوند تا سایت منتشرشده به‌روز شود.
مسیرها را دقیقاً رعایت کن (فایل باید در همان پوشه جایگزین شود):

  index.html                 ->  ریشهٔ مخزن
  content.json               ->  ریشهٔ مخزن
  favicon.svg                ->  ریشهٔ مخزن
  assets/js/main.js          ->  داخل پوشهٔ assets/js
  assets/css/styles.css      ->  داخل پوشهٔ assets/css
  admin/config.yml           ->  داخل پوشهٔ admin

روش آپلود (بدون نصب هیچ برنامه‌ای):
۱. به صفحهٔ مخزن خود در github.com برو.
۲. دکمهٔ "Add file" -> "Upload files" را بزن.
۳. این ۶ فایل را با همین ساختار پوشه بکش و رها کن (drag & drop).
   اگر کل پوشه را بکشی، گیت‌هاب خودش ساختار پوشه‌ها را حفظ می‌کند.
۴. پایین صفحه "Commit changes" را بزن.
۵. حدود یک تا دو دقیقه صبر کن تا GitHub Pages دوباره منتشر کند.
۶. سایت را با Ctrl+Shift+R باز کن.

اگر فقط می‌خواهی نوار متحرک و نشانگر موس درست شود، حداقل این دو فایل لازم است:
  assets/js/main.js
  assets/css/styles.css
